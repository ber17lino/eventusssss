# Eventus Backend API

Бэкенд рекомендательной системы мероприятий «Ивентус» для студентов ТюмГУ.

## 🚀 Быстрый старт (Docker)

```bash
# 1. Клонировать
git clone <url-репозитория>
cd eventus-backend

# 2. Создать .env из примера
copy .env.example .env
# Отредактировать .env — вставить реальные ключи GigaChat

# 3. Запустить
docker-compose up -d

# 4. Открыть документацию
# http://localhost:8000/docs
